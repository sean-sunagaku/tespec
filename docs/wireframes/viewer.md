# tespec viewer — 画面設計

## 画面遷移フロー

```
┌─────────────┐
│  Dashboard  │──── YAML 変更 → SSE → 自動更新
│  (/)        │
└──┬──┬──┬────┘
   │  │  │
   │  │  └─── setup クリック ──→ ┌─────────────────┐
   │  │                         │  Setup 詳細      │
   │  │                         │  (/#/setups/:id) │
   │  │                         └────────┬────────┘
   │  │                                  │
   │  │              参照元 screen クリック │
   │  │                    ┌─────────────┘
   │  │                    ▼
   │  └─── screen クリック → ┌─────────────────┐
   │                        │  Screen 詳細     │◄── navigates_to
   │                        │  (/#/screens/:id)│───→ 別の Screen 詳細
   │                        └──────┬──────────┘
   │                               │
   │                    given クリック → Setup 詳細
   │
   └─── unit クリック ───→ ┌─────────────────┐
                          │  Unit 詳細       │
                          │  (/#/units/:id)  │
                          └─────────────────┘

※ 全画面から Dashboard に「戻る」で遷移可能
```

### 2. Screen 詳細 (/#/screens/:id)

```
┌──────────────────────────────────────────────────────────┐
│  ← 戻る                                    project-name  │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  viewer-dashboard                                        │
│  Route: /                                                │
│                                                          │
│  ┌─ Cases (7) ───────────────────────────────────────┐   │
│  │                                                   │   │
│  │  [normal] ページを開く                      ▼     │   │
│  │  ┌──────────────────────────────────────────────┐ │   │
│  │  │ Given: [viewer_running] ← リンク             │ │   │
│  │  │ Steps:                                       │ │   │
│  │  │   1. use:viewer_running                      │ │   │
│  │  │   2. / にアクセスする                        │ │   │
│  │  │ Expect:                                      │ │   │
│  │  │   • サイドバーに screens 一覧が表示される     │ │   │
│  │  │   • サイドバーに units 一覧が表示される       │ │   │
│  │  │   • サイドバーに setups 一覧が表示される      │ │   │
│  │  └──────────────────────────────────────────────┘ │   │
│  │                                                   │   │
│  │  [normal] screen を選択する                  ▶     │   │
│  │  [normal] unit を選択する                    ▶     │   │
│  │  [normal] setup を選択する                   ▶     │   │
│  │  [normal] YAML ファイルを変更する             ▶     │   │
│  │                                                   │   │
│  │  [error]  YAML に構文エラーがある状態で...    ▶     │   │
│  │                                                   │   │
│  │  [boundary] specs が0件のプロジェクトで開く   ▶     │   │
│  └───────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────┘

※ ▼ = 展開中、▶ = 折りたたみ中
※ [normal] = 緑バッジ、[error] = 赤バッジ、[boundary] = 黄バッジ
```

## 操作一覧

| 画面 | 操作 | 遷移先/結果 |
|------|------|------------|
| Dashboard | screen カードクリック | Screen 詳細 |
| Dashboard | unit カードクリック | Unit 詳細 |
| Dashboard | setup 名クリック | Setup 詳細 |
| Screen 詳細 | case 行クリック | 展開/折りたたみ |
| Screen 詳細 | given リンク | Setup 詳細 |
| Screen 詳細 | navigates_to リンク | 別 Screen 詳細 |
| Unit 詳細 | method セクション | cases 表示 |
| Setup 詳細 | 参照元 screen クリック | Screen 詳細 |
| 全画面 | ← 戻る | Dashboard |
| 全画面 | YAML 変更 | SSE で自動更新 |
